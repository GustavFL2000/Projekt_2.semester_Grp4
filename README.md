# 2. Semesterprojekt – Systemudvikling

## Formål
Dette repository indeholder kode for 2. semesterprojektet på datamatikeruddannelsen.  
Projektet følger udviklingsmetoden Unified Process (UP).

---

## Projektstruktur (Unified Process)

### 1. Inception
**Formål:** Afklare projektets scope og krav

**Indhold:**
- Projektplan
- Interessentanalyse
- Risikoanalyse
- Systemvision
- Kravliste
- Use case diagram
- Aktørbeskrivelser
- Ordbog
- Arkitekturforslag

---

### 2. Elaboration
**Formål:** Opbygge forståelse og designe systemet

**Indhold:**
- Udvidede use cases
- Analyseklassediagram
- Systemsekvensdiagrammer
- Designklassediagram
- Designbeslutninger

---

### 3. Construction
**Formål:** Implementere systemet

**Indhold:**
- Kode
- Designopdateringer
- Brugergrænseflade
- Test (JUnit)
- Dokumentation af implementering

---

## Iterationer

Hver fase kan bestå af flere iterationer.  
For hver iteration dokumenteres:

- Plan
- Krav (ændringer)
- Use cases
- Analyse
- Design
- Implementering
- Test
